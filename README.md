# КуулКлевер — Ремесленный хлеб

Статический лендинг по экрану Figma `6:3964`, файл `C18Ier6BfsAiQ2MqgYErqT`.

## Запуск

Из папки проекта:

```sh
python3 -m http.server 4173 --directory dist
```

Открыть http://localhost:4173.

Сборка и зависимости не требуются. HTML, CSS, JavaScript, изображения, SVG и шрифты находятся в `dist/`. Все ресурсы локальные, временных URL Figma в приложении нет.

## Поведение

- Адаптация для мобильных экранов.
- Кнопки выбора ведут к каталогу на странице, предзаказ — к инструкции.
- Категории и варианты подачи фильтруют карточки.
- Фотография перед каталогом открывается в диалоге; закрытие кнопкой, кликом по фону и Escape.
- Заказ открывает действующий каталог ремесленных хлебов КуулКлевер; приложение — официальную страницу приложения.
- Отсчёт до 15:00 использует московское время. Фактическое наличие и доступные даты определяются магазином.

## Особенности исходного макета

Сохранены повторяющиеся названия/характеристики карточек, повторяющийся текст финального блока, изображения и серые места для иллюстраций хранения. Видеофайл и запись хруста в исходнике не предоставлены; декоративный знак воспроизведён как в дизайне. Изменены ошибочные ссылки на коньяк, присутствовавшие у кнопок хлеба.

Шрифты Ubuntu и Playfair Display загружаются локально. Nexa Script взят из доступного шрифта пользователя.
